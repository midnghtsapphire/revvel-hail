## Always-Training

Preferred name: **Always-Training**. Older docs and scripts call the same practice self-heal (`SELF_HEALING_*`, `scripts/agent-self-heal.js`). The practice is education on every job, recorded in [learnings.md](https://github.com/midnghtsapphire/revvel-standards/blob/main/learnings.md).

- **Good to-dos** — patterns that worked. Keep doing them. Teach the next session.
- **Bad to-dos** — patterns that failed. Do not repeat them. Teach the vaccine.
- **Went-raunchy to-dos** — a good to-do that later turned bad (scale, edge case, or context shift). Retire or revise it. Do not treat it as still good.
