Strata Mapping — Testable Tools

Open any viewer below. These are self-contained HTML files. No install. GitHub Pages will serve them once enabled.

Step 1 — Topography Patch

topography-patch.html — loads a public elevation tile sample and lets you walk a coordinate grid.

Step 2 — Gap Fill Viewer

gap-fill-viewer.html — shows a gap; run driver pass to fill it. Player can ignore.

Step 3 prep — Residual Noticing

residual-noticing.html — odd plant / oversized patch cue on a simple map. Spot and mark.
